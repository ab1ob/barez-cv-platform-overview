# 🟦 بارز أفراد — barezz.com

> **هذا الريبو تعريف بالفكرة والمنتج فقط — لا يحتوي على أي كود مصدري.**

## الفكرة

أول منصة عربية متخصصة في **مراجعة وتحسين السير الذاتية بالذكاء الاصطناعي** — مبنية للسوق السعودي والخليجي أولاً، بالعربية أولاً.

## المشكلة التي تحلها

- أغلب أدوات السير الذاتية العالمية لا تفهم العربية ولا سوق العمل الخليجي
- أنظمة تتبع المتقدمين (ATS) ترفض سيراً ذاتية ممتازة بسبب مشاكل شكلية لا يعرفها المتقدم
- الباحث عن عمل لا يملك طريقة موضوعية لمعرفة جودة سيرته قبل التقديم

## ما يقدمه المنتج

- **مراجعة ذكية للسيرة الذاتية**: تحليل شامل يكشف نقاط الضعف ويقترح تحسينات ملموسة
- **تحسين تلقائي**: إعادة صياغة احترافية ترفع توافق السيرة مع الوظيفة المستهدفة
- **أدوات مساندة** للباحثين عن عمل بالعربية والإنجليزية
- **دليل مهني** شامل لسوق العمل
