# بارز أفراد — barezz.com

منصة مراجعة وتحسين سير ذاتية بالذكاء الاصطناعي، بالعربية ولسوق العمل السعودي والخليجي. هذا الريبو يعرّف بالمنتج؛ الكود المصدري خاص.

## لماذا وُجدت

أنظمة فرز المتقدمين (ATS) تُسقط سيراً ذاتية جيدة لأسباب شكلية لا يعرفها صاحبها، وأدوات السير الذاتية العالمية لا تتعامل مع العربية ولا تفهم سوق العمل الخليجي. بارز بُنيت لسد هذه الفجوة من الداخل: تحليلٌ يكشف ما يُسقط السيرة، وتحسينٌ يعيد صياغتها بما يرفع توافقها مع الوظيفة المستهدفة.

## ما تقدمه

| | |
|---|---|
| مراجعة ذكية | تحليل شامل للسيرة يحدد نقاط الضعف ويقترح تحسينات محددة |
| تحسين تلقائي | إعادة صياغة ترفع التوافق مع الوظيفة المستهدفة وأنظمة الفرز |
| أدوات مساندة | أدوات للباحثين عن عمل بالعربية والإنجليزية |
| دليل مهني | دليل لسوق العمل |

تعمل المنصة باشتراكات ودفع إلكتروني كامل، وتخدم عملاء فعليين: [barezz.com](https://barezz.com)
